# GitHub Steps

**Repo name:** `AI-Medical-Image-Analysis`
**Description:** Deep-learning chest X-ray analysis (CNN / MobileNetV2) with a FastAPI web app
**Topics:** medical-imaging, deep-learning, tensorflow, keras, opencv, computer-vision, fastapi, healthcare-ai, python

```bash
git init
git add .
git commit -m "chore: project structure, requirements, gitignore"
git branch -M main
git remote add origin https://github.com/<your-username>/AI-Medical-Image-Analysis.git
git push -u origin main
```
Create the empty repo on github.com first (no README/license, you already have them).

Making it professional: pin a clear README with screenshots, add topics, keep commits small with prefixes (`feat:`, `docs:`, `fix:`), don't push raw datasets, and add a demo GIF/video.
